# ごはん日記

食べたものを記録すると、1日の栄養バランスを100点満点で採点してアドバイスしてくれる食事管理アプリです（あすけん風）。
ビルド不要の静的Webアプリで、データはブラウザの localStorage に保存されます。

## 機能

- **プロフィール登録**: 性別・年齢・身長・体重・活動量・目標から、基礎代謝（Mifflin-St Jeor式）と目標摂取カロリー・PFCを自動計算
- **食事記録**: 朝食・昼食・夕食・間食ごとに食品を検索して追加（ひらがな/カタカナ検索、カテゴリ、よく使う食品、量の調整）
- **マイ食品登録**: データベースにない食品を栄養素つきで登録
- **栄養バランス採点**: エネルギー・たんぱく質・脂質・炭水化物・食物繊維・食塩・カルシウム・鉄・ビタミンCの9項目で採点
- **アドバイス**: 不足している栄養素を多く含む食品のおすすめ、とりすぎの栄養素への改善ヒント
- **体重記録**: グラフで推移を表示、BMI・目標までの残りを表示
- **データのエクスポート/インポート**（JSON）

## 使い方

`index.html` をブラウザで開くだけで動きます。ローカルサーバーで動かす場合:

```sh
npm start   # http://localhost:8080
```

## テスト

```sh
npm test
```

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `css/style.css` | スタイル（ダークモード対応） |
| `js/foods.js` | 食品データベース（約60品目、1食分あたりの概算値） |
| `js/calc.js` | 目標値・採点・アドバイスの計算ロジック |
| `js/app.js` | 画面の描画と操作 |

※ 栄養価は日本食品標準成分表をもとにした目安です。医療的な指導の代わりにはなりません。
